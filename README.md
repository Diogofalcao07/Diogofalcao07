I came to AI through physics. I studied Physics Engineering at Instituto Superior Técnico in Lisbon, and I'm now doing a master's in AI in Society at the Technical University of Munich.

So far, I've worked on robot perception, looked for anomalies in particle-collision data, and helped build a smart shopping assistant. My main interests are computer vision, machine learning, and automation. This GitHub brings together some of that work and a few hackathon projects.

## A few projects

### [Open-set robotic perception](https://github.com/Diogofalcao07/open_set_detector)

During my research internship at the Institute for Systems and Robotics at Técnico, I worked on the perception pipeline for the **TIAGo robot**. I developed and integrated open-vocabulary detection models, including GroundingDINO and ChatRex, to support recognition of unseen objects and interpretation of human gestures.

`Python` · `GroundingDINO` · `ChatRex` · `Robotic perception`

### [ShopWise](https://github.com/Diogofalcao07/Tecstorm)

A smart shopping assistant for people with dietary restrictions. I helped develop the prototype as part of a multidisciplinary team, combining product detection with AI-powered recommendations. We won our category at **Tecstorm 2025**.

The repository includes the shopping interface, backend, and real-time communication with the product-reading workflow.

**Project stack:** Python · FastAPI · Next.js · TypeScript · MQTT · WebSockets

### [Myco](https://github.com/Diogofalcao07/myco)

A browser-agent demo built around a travel-booking interface. It separates the work into a web app, a retriever that trims page content, an API orchestrator, and an agent that plans and executes browser actions.

**Project stack:** Python · React · Playwright · LLMs · DOM pruning

### [Impact Atlas](https://github.com/Diogofalcao07/ngo-intelligence-dashboard)

A team-built hackathon MVP for small NGOs: bringing together information from RSS feeds and web pages, ranking relevant items, identifying potential funding opportunities, and preparing translations and briefings. It's a prototype for local evaluation, not a production service.

**Project stack:** FastAPI · React · TypeScript · SQLite · Docker

## A little more background

Before working on robot perception, I interned at the **Laboratory of Instrumentation and Experimental Particle Physics**, applying machine learning to anomaly detection in LHC proton-collision events. That involved data preprocessing, model training, and statistical validation.

I've also worked on an API for filtering and indexing HTML context for LLM web agents, with token efficiency and prompt-injection prevention as goals. That work earned **2nd place at Munich Hack in 2025**. Earlier, my team reached the **top 10 out of 100 startups at the European Innovation Academy**.
